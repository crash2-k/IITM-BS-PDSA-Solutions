# Merge In Place

## Problem Statement

Given two sorted lists `A` and `B` (ascending order), merge them in place so that after merging both lists are sorted in ascending order and the smallest elements occupy `A` (the first list). Do not use any additional lists; only swap elements between `A` and `B`.

The function implemented is `mergeInPlace(A, B)` which modifies `A` and `B` in-place.

## Example

Input:
```
2 4 6 9 13 15
1 3 5 10
```

Output:
```
1 2 3 4 5 6
9 10 13 15
```
